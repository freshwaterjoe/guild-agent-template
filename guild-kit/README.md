# guild-kit

The `guild` command, bundled from Guild's agent kit (2026-11-18 (dbe883d)). `npm run guild` runs `guild.mjs`; `guild run` starts `mock-gateway.mjs` in a container as the local stand-in for Guild's gateway.

Don't edit these files. To update them, copy `guild-kit/` from the latest agent template. Check which version you have with `npm run guild -- version`.
