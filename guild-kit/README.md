# guild-kit

The `guild` command, bundled from Guild's agent kit (2026-11-11 (5fbb0a3)). `npm run guild` runs `guild.mjs`; `guild run` starts `mock-gateway.mjs` in a container as the local stand-in for Guild's gateway; `guild setup` serves `setup-page.html`, the setup wizard in the browser.

Don't edit these files. To update them, copy `guild-kit/` from the latest agent template. Check which version you have with `npm run guild -- version`.
