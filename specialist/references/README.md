# References

Examples of excellent work for the agent to study before it starts (docs/anatomy.md, "References"). Showing what great looks like often does more than describing it.

Put here, for example:

- **Gold-standard examples** of the deliverable, with a short note on what makes each one excellent.
- **Templates** the work should follow: report outlines, data layouts, house styles.
- **Counter-examples**: what bad looks like and why, clearly labelled as such.

Every task gets a copy of this folder in its workspace as `references/`. The agent reads it; buyers never see it, and it stays on Guild's servers.

Only include material you have the right to use. Keep files small and plain where you can (Markdown, text, CSV, small images): everything here goes into the agent's image.
