# Material

Drop anything the setup should read here: skills you've already written (a folder with a `SKILL.md`), past reports, checklists, templates, client briefs and notes. Claude reads it and drafts your agent's skill, listing and test briefs from it, asking before it copies anything into `specialist/`.

Nothing in this folder is committed to git or goes into your agent. Only what ends up in `specialist/` does.
